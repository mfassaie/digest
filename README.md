# digest

A monorepo for **digest**, an MCP server that fetches web pages through a
real headless browser (CloakBrowser, in Docker) and serves them back as
structured Markdown — a summary, the section outline, one named section,
keywords, or the full document. It replaces Claude Code's built-in WebFetch
with a timeout-safe, JavaScript-rendering alternative.

See **[app/digest/README.md](app/digest/README.md)** for
installation, configuration, tools, and usage.

## Layout

This is a pnpm workspace (`app/*` + `packages/*`):

| Package | Purpose |
|---------|---------|
| [`app/digest`](app/digest) | `@mfassaie/digest` — the published bin: MCP entry point and admin CLI, bundled with esbuild. Its `docker/` payload is generated by the build. |
| [`packages/shared`](packages/shared) | `@digest/shared` — host-side core: types, url, cache, structure, read engine, logging. |
| [`packages/mcp-server`](packages/mcp-server) | `@digest/mcp-server` — MCP tool definitions, dispatch handlers and response formatting. |
| [`packages/docker`](packages/docker) | `@digest/docker` — every Docker concern: host-side container lifecycle + HTTP client, the in-image fetch/convert service, and the image build context. |
| [`packages/e2e`](packages/e2e) | `@digest/e2e` — end-to-end tests driving the built host handlers against a live `digest:local` container. |
| [`packages/tooling-evals`](packages/tooling-evals) | `@digest/tooling-evals` — the HTML-to-Markdown converter eval harness (defuddle chosen, ADR-006). |

```sh
pnpm install
pnpm build        # build all packages (docker context, then the app bundle)
pnpm test         # all package tests
pnpm --filter @digest/docker test          # docker package tests only
```

Key design decisions are noted in code comments by ADR number (converter
choice, container engine, read tool, host-side writing).
