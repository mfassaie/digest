# webfetch-plus

## Description

An MCP server that replaces Claude Code's built-in WebFetch tool with a
timeout-safe alternative. Prevents subagent hangs caused by WebFetch calls
that never return.

## Project Type

CLI tool / MCP server (stdio transport)
